# 🦅 Eagle's Descent: Atchutha Sai Kiran's Portfolio

**Live:** https://shanmuk05.github.io

A hand-built, scroll-driven portfolio. Scrolling takes you from the dawn sky, down through the clouds and the forest canopy, to the forest floor. Each section is a stop on the way down:

| Altitude | Section |
|---|---|
| 12,000 ft · Sky | Hero |
| 8,000 ft · Clouds | About |
| 3,000 ft · Canopy | Experience |
| 1,200 ft · Treetops | Skills |
| 300 ft · Forest | Projects (synced live with the GitHub API) |
| 40 ft · Undergrowth | Education & certifications |
| 0 ft · Landing | Contact |

Built with plain HTML, CSS and JavaScript: no frameworks and no build step. The scenery (mountains, pine forests, clouds, the eagle, fireflies) is generated procedurally as SVG and canvas.

## Editing
- **Projects, skills:** the `PROJECTS` and `SKILLS` arrays at the top of `app.js`. New public repos also appear automatically.
- **Text:** `index.html`
- **Photo / résumé:** `assets/`
